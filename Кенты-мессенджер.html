Два пути

Советую

Свой сервер на Python + Android-приложение

  • Сервер на FastAPI с WebSocket, база PostgreSQL. Всё это крутится на нашем мини-ПК, который стоит дома и работает круглосуточно.
  • Приложение на Kotlin в Android Studio, оно уже стоит.
  • Весь код наш, разберёмся в каждой детали. Медленнее, зато научимся.
  • Начать можно с веб-версии: страница чата на том же сервере, так идею проверим быстрее всего.
Если хочется быстро

Готовый протокол Matrix + свой клиент

  • Ставим сервер Synapse, он уже умеет чаты, файлы, шифрование и звонки.
  • Сверху делаем свой интерфейс и фишки для кентов.
  • Работает надёжно с первого дня, но своего кода меньше, а сервер тяжелее.
