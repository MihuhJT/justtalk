# JustTalk

Исходный код мессенджера JustTalk: Android, iOS, macOS, Windows, сервер и административная панель.

## Настройка

В репозиторий не входят базы данных, медиа пользователей, административные токены, ключи и локальные настройки. Не добавляйте их в Git.

- Сервер: исходники в `server/`. Для запуска требуются Python и зависимости проекта, включая FastAPI и Uvicorn. Сервер создаёт локальные файлы данных и административный токен при запуске.
- Android: проект в `android/`. Значение `MAPKIT_API_KEY` задаётся в `android/local.properties`; адрес сервера можно задать там как `JT_SERVER`. По умолчанию debug использует адрес эмулятора `10.0.2.2`, а release — локальный адрес устройства.
- iOS и macOS: исходники в `ios/` и `mac/`. Сервер задаётся переменной окружения `JT_SERVER`; по умолчанию используется `http://127.0.0.1:8000`. Для телефона это адрес самого телефона, поэтому настройте адрес доступного сервера перед запуском.
- Windows: проект Electron в `windows/`; адрес сервера задаётся переменной окружения `JT_SERVER`.
- Панель в `panel/` содержит пример настроек для администратора и требует настройки адресов и путей для вашей установки.

Проект находится в разработке. Идентификаторы приложений, названия эндпоинтов и идентификаторы пользователей в исходном коде являются частью протокола и не являются ключами доступа.
